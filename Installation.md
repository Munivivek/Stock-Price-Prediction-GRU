# Project Setup Guide

### Step 1: Install Prerequisites
Before setting up the project, ensure you have the following installed on your system:
- [Visual Studio Code (VS Code)](https://code.visualstudio.com/)
- [Python 3.12.0](https://www.python.org/downloads/release/python-3120/)

## Step 2: Set Up a Virtual Environment and Install Dependencies

1. Open VS Code.
2. Open the terminal in VS Code (`Ctrl + ~` or navigate to **Terminal > New Terminal**).
3. Navigate to your project directory using the command:
   
   cd path/to/your/project
   
4. Create a virtual environment using the following command:

command: python -m venv venv
   
5. Activate the virtual environment:

command:  venv\Scripts\activate

6. Install the required dependencies from `requirements.txt`:

command: pip install -r requirements.txt

## Step 3: Run the Application
Once the environment is set up and dependencies are installed, run the application using:

command: python app.py


Your application should now be up and running!
